# candleful-bali

## Dumblab  
Это веб-приложение, где трейдеры и инвесторы делятся своими идеями, аналитикой и мнениями о рынках. Пользователи могут публиковать посты, подписываться на других участников и формировать свою лудоленту.

### Для регистрации пользователя требуется 
- email
- Ник
- пароль

### Права пользователей
 - Неавторизованный пользователь НЕ может подписываться на других,оценивать посты,может только смотреть 

 - Авторизованный пользователь может писать посты, писать комменты,подписываться на других
- Админ отвечает за модерацию соответственно,удаляет посты,банит


### Функциональные требования
Фильтрация и поиск по тикерам должна быть реализована
На главной ленте посты идут по дате загрузки,и скорее всего по количествам подписчиков автора.

# Посты
- можно прикреплять изображения
- можно указать тикер инструмента. нажатие на тикер перенаправит на сторонний сайт с описанием инструмента
- авторизованный пользователь может редактировать свои посты
- в комментариях можно будет тегать пользователя

# Социальные взаимодействия
- Авторизованный пользователь может подписаться на другого или отписаться
- Все могут просматривать подписчиков пользователя
- У пользователя будут пассивные уведомления - отображение непрочитанных комментариев/подписки от других пользователей
